# Career Skill Gap Analyzer
### SLIIT ITP Project — IT24 Group 02 | Malabe Campus

---

## 🎓 Project Overview
A full-featured React web application for SLIIT undergraduates to assess their skills, identify career-readiness gaps, and get personalized learning recommendations.

## 🚀 Quick Start (VS Code)

### Prerequisites
- Node.js v16+ ([Download](https://nodejs.org))
- VS Code ([Download](https://code.visualstudio.com))

### Setup Steps

```bash
# 1. Open this folder in VS Code
# 2. Open the integrated terminal (Ctrl + `)

# 3. Install dependencies
npm install

# 4. Start the development server
npm start

# App opens at http://localhost:3000
```

---

## ✨ Features (6 Core + Registration)

| # | Feature | Description |
|---|---------|-------------|
| 0 | **User Registration & Login** | Register with SLIIT details, sign in with email |
| 1 | **Skill Assessment** | Rate technical & soft skills via questionnaire |
| 2 | **Career Path Mapping** | Explore IT career paths & required skill levels |
| 3 | **Career Recommendation** | Get matched to best-fit careers with % scores |
| 4 | **Skill Gap Identification** | Visual comparison of your skills vs requirements |
| 5 | **Learning Resources** | Curated courses from Coursera, Udemy, freeCodeCamp |
| 6 | **Progress Tracking & Analytics** | Charts, trends, and achievement badges |

---

## 🎨 Design
- **Theme:** Deep dark blue + purple gradient
- **Fonts:** Sora (headings) + DM Sans (body)
- **Framework:** React 18 (no router needed — custom navigation)
